# Scrcpy Mobile 文档说明

`docs/` 现在不再作为对外主入口。

当前推荐入口：

- GitHub Wiki 源：`/wiki`
- GitHub Wiki 页面：<https://github.com/XRSec/scrcpy-mobile/wiki>

## 文档分工

- `wiki/`
  - 面向 GitHub Wiki
  - 分为“用户使用文档”和“开发文档”
  - 只保留当前有效、适合持续维护的内容

- `docs/`
  - 面向仓库内参考资料
  - 保留部分历史分析、排障记录、架构草稿和研究文档
  - 不再承担主要导航职责

## 使用建议

- 想看怎么使用：优先看 wiki 的用户文档
- 想看当前实现：优先看 wiki 的开发文档
- 想补充查历史材料：再回到 `docs/`
