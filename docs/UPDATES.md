# 更新日志

## 4.4.3.3

发布日期：2026-07-21

### 新功能

- 新增面向低延迟远控的游戏模式，提供 720/1080/1920、1M/2M/4M 与 60/90/120 fps 受控档位，并在会话列表显示“游戏”标签。
- 游戏模式使用独立高优先级控制与视频解码线程，优化连续移动、视角转动、短按和高帧率画面的响应；运行期间自动暂停悬浮球、性能浮层、调试日志和 mDNS 后台发现，减少无关开销。
- 增强虚拟屏模式：支持选择并启动远端 App 或启动器，可同步、交换或清空虚拟屏尺寸，并可控制系统界面及断开后的内容保留行为。
- 会话参数新增纵向滑动选择器，统一最大尺寸、视频码率、最大帧率和音频码率的预设与自定义输入体验。
- 会话新增“显示悬浮球”开关，可按会话决定是否显示快捷操作入口；游戏模式下始终隐藏。
- 设置页新增“显示帧率与网络速率”，可在远控页面查看 Decode/Render FPS、视频码率、Wi-Fi 链路速率及应用实际网络吞吐。
- 远控悬浮菜单新增“适配设备分辨率”，可将目标设备切换为本机分辨率，再次点击即可恢复。
- 首次访问介绍卡片和最近更新卡片补充端口转发、虚拟屏与游戏模式说明。
- 增加每日自动检查更新

### 体验优化

- 重构会话级配置与运行态共享：以 `ScrcpyConfig`、`Session` 和 `ActiveScrcpyConnection` 分别承载配置、会话状态与活动连接，移除重复字段、全局注册表及多层 Runtime Store/Lifecycle/Facade 转发；Profile 现作为完整配置预设应用。
- 将布尔 `useAdbForward` 升级为 `ScrcpyTunnelMode`，统一 ADB Forward 与 Direct ADB 通道选择；video、audio、control socket 继续严格按协议顺序建立。
- 压平 ADB 建链路径，候选竞速直接返回真实 `AdbConnection`，删除 `deviceId` 二次查池、重复传输分流和单行回调包装；会话始终绑定实际竞速胜出设备。
- 统一重连与清理生命周期：重连次数由 Session 单点管理，连接成功自动复位；连接、重连、断开和取消共享互斥边界，主动清理进入不可中断阶段。
- 整理会话配置项，明确 ADB 转发、粘贴板同步、断开清理及控制端/远程设备唤醒语义；远程唤醒与断开清理默认关闭，保留可复用资源以减少后续连接准备时间。
- 重写多指触控发送与控制消息调度：保持稳定 pointer ID、合并过期 MOVE，并在 DOWN、UP、按键和文本消息之间维持严格顺序，降低游戏场景的触控积压。
- 游戏模式保证极短 DOWN/UP 在被控端具有可见按压时长，改善跳跃、开火等短按被连续 MOVE 延迟的问题。
- 简化音视频编解码器配置，强化远端编码器与本机解码器的自动匹配、能力检测和运行时失败回退。
- 编码器检测启用 `cleanup=false` 并复用主 server 文件，移除 `scrcpy-server2.jar` 复制流程。
- 优化 Surface 切换和硬解输出等待，减少 UI 重组造成的重复切换及解码完成后的额外等待。
- 重构悬浮球四边贴靠、半隐藏、拖动和菜单定位逻辑，适配横竖屏、系统栏、刘海和侧边导航区域；菜单与球保持安全间距。
- 远控页面可跟随目标画面方向自动切换本机横竖屏。
- 改进远端 UI 布局识别，对自定义按钮、复选框、协议勾选项、启用状态和选中状态的识别更准确。
- 远控“发送文件”选择 APK 时可直接安装，并与应用管理复用同一安装流程。

### 问题修复

- 修复重连成功后次数未复位、同一请求重复触发、旧 Socket/Forward/Server 清理与新连接竞态，以及 ADB 缓存缺失时无法按会话候选重建的问题。
- 修复初始连接阶段取消可能遗留 Session、协程取消被误报为连接失败、重连页面返回行为异常，以及主动关闭 Socket 被误判为再次断线的问题。
- 修复控制流读取超时导致约 10 秒后误重连；握手完成后媒体与控制流改为依靠关闭 Socket 中断阻塞读取。
- 将 Wi-Fi/ADB 断开产生的流关闭统一视为生命周期信号，避免音频、视频和 Shell 监控重复打印 `AdbConnectionClosedException` 堆栈，同时保留真实协议与解码错误详情。
- 优化双向粘贴板同步，提升中文、特殊字符和大段文本的粘贴可靠性。
- 修复主动断开或取消连接后，待执行的自动重连仍可能重新发起连接的问题。
- 修复会话快捷保存可能新增重复会话、分组选择保存不完整，以及删除分组后会话残留无效分组引用的问题。
- 修复悬浮菜单在顶部、底部及横屏侧边出现弹回、消失、遮挡或定位不一致的问题。
- 修复部分设备的音频解码输出、mDNS 在线状态、键盘输入和远控 UI 渲染细节问题。
- 更新部分弃用 Android API 的兼容实现。
