# Contributing to Screen Remote

Thank you for your interest in Screen Remote.

Screen Remote is a remote control and device management app for Android devices. The public
repository contains documentation and project materials, while the core application source code is
currently kept private to prevent unauthorized commercial use and redistribution.

## How to Get Involved

If you would like to contribute, please open an issue and briefly introduce:

- What you would like to work on
- Your relevant Android, Kotlin, Compose, ADB, scrcpy, networking, or documentation experience
- Whether you are interested in code, testing, documentation, translation, design, or feedback
- Any devices or Android versions you can help test

Based on the topic and project needs, maintainers may invite suitable contributors to the private
source repository.

## Helpful Contribution Areas

Contributions are especially welcome in these areas:

- Testing remote control flows across different Android versions, device brands, and connection
  types
- Reporting clear bugs with reproduction steps, logs, screenshots, and device information
- Improving English and Chinese documentation
- Reviewing UX details for remote control, device management, Wireless Debugging, and settings
- Researching ADB, scrcpy, codec, latency, and Android compatibility behavior

## Issue Guidelines

When opening an issue, please include enough detail for maintainers to understand and reproduce the
problem:

- App version or commit, if available
- Controlling device model and Android version
- Target device model and Android version
- Connection type: USB Host, TCP, or Wireless Debugging
- Expected behavior and actual behavior
- Steps to reproduce
- Relevant logs, screenshots, or screen recordings

Please remove private data before sharing logs or screenshots, including pairing codes, IP addresses
that should not be public, file contents, clipboard data, account names, and device identifiers.

## Source Access and Trust

Access to the private source repository is granted selectively. Contributors with source access are
expected to:

- Use the code only for approved project work
- Avoid sharing private source code, internal builds, or unpublished implementation details
- Respect the project's licensing and commercial-use boundaries
- Keep discussion constructive, technical, and respectful

## Pull Requests

Public pull requests are welcome for documentation and repository materials that are available in
this repository. For private source changes, please coordinate with maintainers first through the
issue where the work is discussed.

Before proposing a change, make sure it is focused, documented when necessary, and easy to review.

## Security and Sensitive Reports

If you find a security issue or a bug that exposes private data, please avoid posting sensitive
details publicly. Open an issue with a high-level description and ask for a private contact path.

## Thank You

Even if the full source is not public yet, careful testing, thoughtful bug reports, documentation
improvements, and technical research all help make Screen Remote better.
